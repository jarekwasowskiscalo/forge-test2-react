# User feedback — session

`/sdd-retro` creates this file and **nothing and nobody fills it in but you**. The agent
leaves two documents of its own beside it: `summary.md` says what happened, `audit.md` says
how the agent judges it. A third statement is missing — yours. Only three independent
statements about the same run show what the agent does not know about itself.

Empty is fine: `verify` does not block on it and the commit will pass. An empty section is
data, not a fault — but a filled-in section is the one thing in this archive no number can
replace.

The retro round (the prompt `${CLAUDE_PLUGIN_ROOT}/retro-prompts/round.md`, which travels with the
forge plugin) reads it, setting your judgement against the
session's self-assessment and against the metrics.
